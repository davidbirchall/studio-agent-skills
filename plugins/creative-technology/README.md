# squad-skills-creative-technology

Creative technology and asset pipeline skills for Unity: Blender workflows, 3D and 2D asset pipelines, asset optimisation, material and shader workflows, VFX implementation, animation integration, and audio integration. Covers technically preparing and integrating assets, not creating them.

Version `0.1.0`, 8 skills.

## Install

```
copilot plugin install ./plugins/creative-technology
```

## Skills

| Skill | Purpose | Load when |
|-------|---------|-----------|
| `2d-asset-pipeline` | Sprites, atlases, pixels per unit, tilemaps, compression, colour space | Bringing 2D assets into Unity |
| `3d-asset-pipeline` | FBX/glTF export, scale and axes, Unity import settings, prefabs, validation | Bringing 3D assets into Unity |
| `animation-integration` | Rigs, import settings, Animator structure, root motion, events | Integrating animation |
| `asset-optimisation` | Budgets, LODs, texture compression, atlasing, CI budget checks | Reducing asset cost |
| `audio-integration` | Import settings, loudness, mixer, voice limits, music, middleware | Integrating audio |
| `blender-workflows` | Scene units, modifiers, naming, bpy batch export, .blend versioning | Preparing assets in Blender |
| `material-shader-workflows` | Render pipeline, Shader Graph vs HLSL, variants, texture packing, SRP Batcher | Building materials and shaders |
| `vfx-implementation` | Particle System vs VFX Graph, pooling, overdraw, gameplay hooks | Implementing effects |

## Related plugins

Works well with: game-development, creative. Skills may mention skills from other plugins in a short "See also" note; each skill stands on its own if those plugins are not installed.
