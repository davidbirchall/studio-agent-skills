# squad-skills-business

Solo-business skills for individual makers of software and games: licensing and IP, privacy and data retention, pricing and monetisation, payments and billing, and product analytics. Provider-neutral and not legal advice.

Version `0.1.0`, 5 skills.

## Install

```
copilot plugin install ./plugins/business
```

## Skills

| Skill | Purpose | Load when |
|-------|---------|-----------|
| `licensing-and-ip` | Licensing and intellectual property for a solo maker of software and games - choosing a licence for your own code (permissive, copyleft,... | Picking a licence, adding a dependency or asset, shipping a build, using AI-generated content, or naming a product |
| `payments-and-billing` | Payments and billing architecture for a solo maker - payment provider categories (merchant of record versus payment processor and what each handles... | Integrating payments, handling webhooks, modelling subscriptions or entitlements, or debugging billing state |
| `pricing-and-monetisation` | Pricing and monetisation for a solo maker of software and games - pricing models (one-time, subscription, usage-based, freemium, ads, in-app... | Setting or changing a price, choosing a business model, designing tiers or trials, adding in-app purchases or ads, or reviewing monetisation for manipulative patterns |
| `privacy-and-data-retention` | Privacy and data retention for a solo maker of software and games - data inventory (what, why, where, how long), data minimisation, lawful basis and... | Collecting a new kind of user data, adding a third-party service or analytics, building account deletion or export, handling LLM inputs, or writing a privacy policy |
| `product-analytics` | Product analytics for a solo maker of software and games - events as a typed schema with naming conventions, what to measure first (activation,... | Adding analytics, defining events or metrics, building a dashboard, running an experiment, or deciding what to build next from usage data |

## Related plugins

Works well with: backend, frontend, game-development, product. Not legal advice; flag decisions needing a qualified professional. Each skill stands on its own if other plugins are not installed.
