# squad-skills-production

Production-process skills for software, games, and creative projects: planning, scope, prioritisation, estimation, milestones, release, and retrospective.

Version `0.2.0`, 7 skills.

## Install

```
copilot plugin install ./plugins/production
```

## Skills

| Skill | Purpose | Load when |
|-------|---------|-----------|
| `planning` | Turning an idea into a workable project plan - goal and outcome definition, stakeholders, constraints, assumptions, risks... | Starting a project, phase, or initiative, when a goal is vague, or when asked to plan, kick off, or structure... |
| `scope` | Defining and defending project scope - in-scope and out-of-scope lists, deliverables, acceptance criteria, definition of done... | Fixing what a project will and will not deliver, when requests keep expanding, or when asked to write a scope... |
| `prioritisation` | Ordering work by value and cost - MoSCoW, RICE scoring, Kano model, cost of delay and weighted shortest job first, value vs... | Deciding what to do first, cutting a backlog to fit a deadline, resolving competing requests, or asked to... |
| `estimation` | Estimating effort and duration under uncertainty - ranges, three-point (PERT) estimation, reference-class estimation, relative... | Sizing work, forecasting a date, building a schedule or budget, or asked how long something will take or how... |
| `milestones` | Sequencing work into milestones - outcome-based checkpoints, vertical slice, exit criteria, schedule with dependencies and... | Building a schedule or roadmap, defining phase gates, tracking delivery, deciding what to cut when behind, or... |
| `release` | Preparing and executing a release or launch - go/no-go criteria, release checklist, staged rollout, rollback plan, communications... | Shipping, launching, publishing, or handing over a deliverable, when deciding whether something is ready, or... |
| `retrospective` | Running blameless retrospectives and post-project reviews - evidence gathering, start/stop/continue and other formats, root-cause... | A milestone, release, or project ends, after an incident or missed date, or when asked to run a retro... |

## Related plugins

Works well with: product, game, knowledge, platform-engineering (release-management). Skills may mention skills from other plugins in a short "See also" note; each skill stands on its own if those plugins are not installed.
