# squad-skills-creative

Creative-process skills for games, film, animation, books, and brands: creative direction, art direction, visual development, worldbuilding, narrative, and character design.

Version `0.1.0`, 6 skills.

## Install

```
copilot plugin install ./plugins/creative
```

## Skills

| Skill | Purpose | Load when |
|-------|---------|-----------|
| `creative-direction` | Defining and guarding the creative vision of a project - creative brief, audience, tone, experience goals, creative pillars... | Starting a project, writing or reviewing a creative brief, setting pillars, resolving conflicting creative... |
| `art-direction` | Establishing and maintaining a coherent visual language - mood boards, style guide, shape language, colour palette and value... | Translating a creative brief into a visual style, writing a style guide, reviewing assets for consistency, or... |
| `visual-development` | Exploring and proving the look of a project before and during production - thumbnails, concept and environment studies, colour... | Exploring visual options, building a colour script, designing key environments or keyframes, pitching a look... |
| `worldbuilding` | Designing coherent fictional settings - premise and scope, the worldbuilding iceberg, rules of the world, geography, history... | Inventing a setting, writing a world bible, checking a world for contradictions, deciding how much to build... |
| `narrative` | Structuring stories - premise, theme, stakes, logline, three-act structure, hero's journey, story beats, scene goals and conflict... | Developing a plot, writing a logline or synopsis, building a beat sheet, diagnosing a sagging middle or weak... |
| `character-design` | Designing characters as people and as visuals - role, want versus need, flaw, ghost or backstory, voice, relationships, arc... | Creating or reviewing a protagonist, antagonist, or cast, writing a character profile, planning an arc, or... |

## Related plugins

Works well with: creative-technology, game, product. Skills may mention skills from other plugins in a short "See also" note; each skill stands on its own if those plugins are not installed.
