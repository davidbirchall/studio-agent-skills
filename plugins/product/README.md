# squad-skills-product

Product process skills: idea shaping, discovery, user research, UX design, product definition (PRD), and feature design.

Version `0.1.0`, 6 skills.

## Install

```
copilot plugin install ./plugins/product
```

## Skills

| Skill | Purpose | Load when |
|-------|---------|-----------|
| `idea` | Turn a raw product idea into a sharp, testable concept - problem statement, target user, value hypothesis, riskiest assumptions... | Someone proposes a new product, feature direction, or "what if we..." and it needs shaping before any... |
| `discovery` | Product discovery process - frame the outcome, map the opportunity space with an opportunity solution tree, run the double... | An idea has been shaped and the team must decide which problems and solutions to pursue, or when scope is... |
| `user-research` | Plan and run user research - research questions, method choice (interviews, usability tests, surveys, diary studies), Mom Test... | Discovery has open questions about users, when preparing interviews or usability tests, or when turning raw... |
| `ux-design` | UX design process - turn research into user flows, information architecture, story maps, wireframes, and usability-tested... | Research findings need to become concrete experience designs, when mapping end-to-end user journeys or flows... |
| `product-definition` | Write a product requirements document (PRD) - problem, goals and non-goals, users, prioritised requirements (MoSCoW), acceptance... | A validated, designed opportunity must be turned into a scoped definition that engineering, design, and... |
| `feature-design` | Detail a single feature from a PRD into build-ready form - user stories (INVEST), behaviour rules, edge cases and error states... | A requirement or story-map slice is approved and needs to be broken down for delivery, or when a feature spec... |
