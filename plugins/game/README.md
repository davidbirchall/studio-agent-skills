# squad-skills-game

Engine-agnostic game design skills: game idea, game design, mechanic design, systems design, progression design, level design, and balance, with playtesting guidance.

Version `0.1.0`, 7 skills.

## Install

```
copilot plugin install ./plugins/game
```

## Skills

| Skill | Purpose | Load when |
|-------|---------|-----------|
| `game-idea` | Turn a vague game concept into a testable pitch - player fantasy, hook, genre and audience, game pillars, scope, and a one-page... | Starting a new game, brainstorming concepts, writing a pitch, choosing between ideas, or defining pillars |
| `game-design` | Define the overall design of a game from an approved concept - target player experience using the MDA framework (mechanics... | Turning a concept into a design, writing or reviewing a design doc, defining the core loop, or planning first... |
| `mechanic-design` | Specify individual game mechanics - player verbs, rules, inputs, feedback, risk/reward, meaningful choices, and edge cases - so... | Designing an action, ability, combat or movement rule, puzzle rule, or reviewing whether a mechanic creates... |

| `progression-design` | Design how players advance over time - power curve, skill and knowledge progression, unlock pacing, rewards and motivation... | Planning levels or XP, unlocks, skill trees, rewards, tutorial flow, pacing across a session or campaign, or... |
