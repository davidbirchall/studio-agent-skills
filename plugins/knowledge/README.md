# squad-skills-knowledge

Domain-agnostic knowledge-work skills: research practice, knowledge capture, decision-making, documentation, and review. A chained workflow from question to evidence, notes, decisions, written artifacts, and feedback.

Version `0.2.0`, 8 skills.

## Install

```
copilot plugin install ./plugins/knowledge
```

## Skills

| Skill | Purpose | Load when |
|-------|---------|-----------|
| `decision-making` | Making and recording decisions well - clarifying the decision and criteria, generating options, classifying reversible (two-way... | Choosing between alternatives, committing to a direction, or documenting why a choice was made |
| `documentation` | Writing clear documentation for a defined audience using the Diataxis framework - tutorials, how-to guides, reference, and... | Creating or restructuring guides, handbooks, READMEs, procedures, or reports, or when existing documents mix... |
| `knowledge-capture` | Capturing and organizing knowledge as durable, atomic, linked notes - fleeting vs literature vs permanent notes (Zettelkasten)... | Turning research, meetings, reading, or experience into reusable notes, or when a note collection is hard to... |
| `personal-knowledge-base` | Structuring a durable plain-Markdown personal knowledge base that one user and AI sessions can both query - folder layout (inbox, notes by topic,... | Creating, reorganizing, searching, or maintaining a personal notes folder, or deciding where a piece of knowledge should live |
| `rapid-domain-learning` | Getting competent in an unfamiliar domain quickly - defining the target capability and a question list, finding the 20 percent core in primary... | Starting work in a domain, tool, or technology you do not yet know well, or when asked to get up to speed on a subject before acting |
| `research-practice` | Structured research for any topic - framing a research question, planning searches, evaluating and triangulating sources... | Asked to investigate, compare options, verify a claim, or gather evidence before capturing notes or making a... |
| `review` | Reviewing any written work, research, plan, or decision with a checklist and giving actionable feedback - agreeing scope and... | Asked to review, critique, proofread, fact-check, or give feedback on a document, finding, or decision record |
| `source-summarisation` | Summarising documents, articles, transcripts, code, and discussion threads into reusable notes - purpose-first framing, a fixed structure of claims,... | Asked to summarise, digest, extract, or compare sources, or when turning raw material into a note that later work will rely on |
